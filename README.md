# 음성번역

휴대폰 브라우저에 설치해 쓰는 개인용 앱(PWA)입니다. 빌드 과정이 없고, `main` 브랜치에 올리면 GitHub Pages에 자동으로 배포됩니다.
API 키는 파일에 들어 있지 않고 각 휴대폰의 앱 저장소에만 저장됩니다.

## 설치

1. 앱 주소: https://stonylee.github.io/voice-translator/
2. 휴대폰에서 그 주소를 열고 홈 화면에 추가합니다.
   - 아이폰: Safari → 공유 → 홈 화면에 추가
   - 안드로이드: Chrome → 메뉴 → 앱 설치(또는 홈 화면에 추가)
3. 앱의 설정에 OpenAI API 키를 넣고 `키 확인`을 누릅니다. OpenAI 대시보드에서 이 앱 전용 키를 만들고 월 사용 한도를 걸어 두는 것을 권장합니다.

## 비용

- 음성 인식 `gpt-live-transcribe`: 분당 $0.017. 큰 소리가 감지된 구간만 전송합니다.
- 번역: 영어·일본어 문장을 말하는 동안에도 반복 호출하므로 대화량에 비례해 늘어납니다. 설정의 빠른 모드를 켜면 번역 토큰 요금이 2배입니다.

## 동작 방식

- 듣는 방식: `회의`는 소음보다 큰 모든 목소리를 보내고 전부 표시합니다(기본값). `큰 목소리만`은 최근 최대 음량 기준도 함께 적용합니다. 두 방식 모두 설정의 `듣는 범위`로 조절합니다.
- 회의 분야: 한국어, English, 영어/한국어, 일어/한국어에서 건설·법률을 고르면 음성 인식 힌트와 번역 규칙을 함께 보냅니다.
- 목소리 구별: 음높이와 음색을 휴대폰에서 분석해 발화 단위로 A, B, C…를 붙입니다. 화면에는 큰 두 목소리만 보이고, 나머지는 저장 파일에 원문으로만 남습니다.
- 교정 사전: 문장을 누르거나 설정에서 열어 틀린 표현과 맞는 표현을 등록합니다. 문장을 자동으로 바꾸고 맞는 표현은 음성 인식 힌트로 보냅니다. 휴대폰에만 저장되며 앱을 지우면 사라질 수 있습니다.
- 언어 자동: 인식된 글자 종류로 한국어·영어·일본어를 판별합니다. 스페인어·중국어는 언어 메뉴에서 직접 고를 때만 번역합니다.

## 점검

- 화면 데모(마이크·API 불필요): 주소 뒤에 `?demo=1`
- 테스트: `node --test test/`
